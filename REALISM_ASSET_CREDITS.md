## Tools and dependencies

Blender 4.5.14 LTS and MPFB 2.0.18 are authoring tools. MPFB code is GPL-3.0; the selected generated model assets are CC0, as listed in the official system catalogue. Blender and MPFB are not runtime game dependencies. Their software licenses remain in the downloaded source. Unity 6000.3.24f1, URP 17.3.0, Cinemachine 3.1.5 and Input System are retained. Unity Pipeline 0.8.0-exp.1 was added for editor automation; it is not gameplay code. Packages/manifest.json and packages-lock.json record exact dependencies.

Original MakeHuman file headers and Kenney License.txt files are retained. Poly Haven source.json files contain author metadata, API version hash, download URLs and checksums. No downloaded paid asset is used. Legacy prototype assets remain in the project for recovery.
